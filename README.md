# Фитнес-тренер для Android

[Откройте страницу загрузки](https://pavliksergeev378-eng.github.io/fitness-agent-downloads/) на телефоне, введите ключ, полученный от владельца приложения, и нажмите «Скачать APK». Архиватор больше не нужен.

Страница получает зашифрованный файл и готовит APK в браузере. Ключ не отправляется в GitHub и не хранится на странице. Публичный репозиторий содержит только страницу и зашифрованный файл, без исходников приложения, пароля и ключа подписи.

После загрузки откройте APK на телефоне с Android 9 или новее и следуйте подсказкам установки. Если ранее была установлена тестовая сборка с другой подписью, сначала сохраните её данные через «Резервная копия».

SHA-256 готового APK версии 0.2.0: 9C24DDF004AA6720273AF4CE1ACF227FAF8979A15F94F49749BE54EFACAAB036.

Для владельца: tools/encrypt.mjs шифрует APK с ключом из отдельного локального файла; tools/test-decrypt.mjs проверяет целостность и отказ при неправильном ключе. Ключ никогда не добавляйте в Git.
