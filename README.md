# Фитнес-тренер для Android и ПК

[Страница скачивания](https://pavliksergeev378-eng.github.io/fitness-agent-downloads/) позволяет выбрать Android или ПК и ввести один и тот же ключ, полученный от владельца. Вход в GitHub и архиватор не нужны. После подготовки нажмите отдельную кнопку скачивания: это позволяет браузеру сохранить файл по явному нажатию пользователя.

Android: установите APK поверх текущей версии. В 0.2.4 следующие обновления готовятся внутри приложения в одном временном файле с последующей очисткой. Старые APK в Загрузках удалите отдельно.

ПК: сохраните FitnessAgent-PC.html и откройте в Chrome или Edge. Это автономная версия со встроенными картинками; установка, сервер, контейнер и ЛЛМ не нужны. Данные остаются в этом браузере. Для переноса между устройствами или браузерами используйте Резервную копию. Health Connect читается на Android; записи можно перенести копией с телефона.

При обновлении ПК сохраните резервную копию, замените файл в прежней папке и открывайте его тем же браузером. Chrome / Edge предлагают выбрать место сохранения: можно указать прежний файл и подтвердить замену, чтобы не создавать дубликаты.

Публичный репозиторий содержит страницу, сведения о выпусках и зашифрованные файлы. Ключ используется только локально, исходники приложения и ключ подписи не опубликованы. downloads.json описывает обе платформы, version.json — обновления Android, pc-version.json — обновления ПК. Номер выпуска меняется после подготовки готовых файлов; обычный коммит исходников ещё не означает обновление приложения.

Для владельца: tools/encrypt.mjs шифрует любой файл ключом из отдельного локального файла; tools/test-decrypt.mjs проверяет расшифровку и отказ при неверном ключе. Никогда не добавляйте ключ в Git.
