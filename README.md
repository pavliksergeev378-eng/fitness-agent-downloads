# Фитнес-тренер для Android

[Откройте страницу загрузки](https://pavliksergeev378-eng.github.io/fitness-agent-downloads/) на телефоне, введите ключ, полученный от владельца приложения, и нажмите «Скачать APK». Архиватор больше не нужен.

Страница получает зашифрованный файл и готовит APK в браузере. Ключ не отправляется в GitHub и не хранится на странице. Публичный репозиторий содержит только страницу и зашифрованный файл, без исходников приложения, пароля и ключа подписи.

После загрузки откройте APK на телефоне с Android 9 или новее и следуйте подсказкам установки. Новую версию ставьте поверх текущей: профили, программы и дневник останутся на телефоне. В приложении есть кнопка «Обновления» и проверка версии при запуске. Если ранее была установлена тестовая сборка с другой подписью, сначала сохраните её данные через «Резервная копия».

SHA-256 готового APK версии 0.2.3: E5BCCE18A8B84EDF14928C55C43087A1F634713F7EDE4F66E47DD8AC3426D423. Версия для проверки обновлений записана в docs/version.json. Исходный код на GitHub сам по себе не обновляет APK: номер версии меняется только после выпуска новой подписанной сборки.

Для владельца: tools/encrypt.mjs шифрует APK с ключом из отдельного локального файла; tools/test-decrypt.mjs проверяет целостность и отказ при неправильном ключе. Ключ никогда не добавляйте в Git.
В версии 0.2.3 формы заполняются готовыми вариантами и числовыми кнопками; подсказки раскрываются нажатием. Найденные темы инструкции открываются кнопками и ведут к соответствующим экранам приложения.
