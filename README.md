# Фитнес-тренер: загрузка для Android

Здесь опубликован только зашифрованный архив приложения. Исходный код, ключ подписи APK и пароль архива не публикуются.

## Скачать и установить

1. [Скачайте последний архив FitnessAgent.7z](https://github.com/pavliksergeev378-eng/fitness-agent-downloads/releases/latest/download/FitnessAgent.7z). Вход в GitHub не требуется.
2. Откройте архив в приложении, которое поддерживает формат 7z с AES-256, и введите пароль, полученный от владельца приложения.
3. Установите извлечённый APK на телефон с Android 9 или новее.

Архив можно скачать без пароля; пароль нужен для распаковки. Не публикуйте его вместе со ссылкой. Если на телефоне установлена тестовая версия с другой подписью, сначала сохраните данные через «Резервная копия» в приложении.

SHA-256 извлечённого APK версии 0.2.0: `9C24DDF004AA6720273AF4CE1ACF227FAF8979A15F94F49749BE54EFACAAB036`.
